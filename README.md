### 🦸‍♀️ Classificador de Nível de Herói
---

Este repositório contém o código desenvolvido para o desafio "Nível do Herói" da plataforma DIO (Digital Innovation One)
---
### 📝 Descrição

O objetivo deste desafio é criar um sistema que, a partir da experiência (XP) de um herói, determine seu nível de acordo com faixas predefinidas.
---
O programa classifica o herói em um dos seguintes níveis:

| Nível      | Faixa de XP    | Emoji |
| :--------- | :------------- | :---: |
| Ferro      | 0 – 1.000      |   🏅  |
| Bronze     | 1.001 – 2.000  |   🥉  |
| Prata      | 2.001 – 5.000  |   🥈  |
| Ouro       | 5.001 – 7.000  |   🥇  |
| Platina    | 7.001 – 8.000  |   💎  |
| Ascendente | 8.001 – 9.000  |   🌟  |
| Imortal    | 9.001 – 10.000 |   ⚡   |
| Radiante   | >= 10.001      |   ✨   |
---
### 💻 Tecnologias Utilizadas

- JavaScript

- Node.js (opcional, para execução local)

- Entrada e saída de dados via console

---

### ⚙️ Funcionamento

O usuário informa o nome do herói e o valor de XP.
O sistema compara o valor informado e exibe uma mensagem com o nível correspondente.

---
### 💬 Exemplo de Saída

Digite o nome do herói: Arthus
Digite o XP do herói: 7200

O Herói de nome Arthus está no nível Platina 💎
